Lumirail Studio — démarrage Electron + Vite (liste des fichiers et dépendances)
================================================================================

1. Commande typique (développement)
-----------------------------------
npm run electron:dev

Équivalent à :
- Vite : cross-env VITE_DESKTOP=1 vite --port 9000
- Electron : wait-on http://localhost:9000 puis NODE_ENV=development electron .


2. Point d’entrée Node / Electron (package.json)
-------------------------------------------------
package.json (champ "main")
electron/main.mjs
electron/preload.cjs
electron/serialBridge.mjs


3. Chaîne d’exécution processus principal
-----------------------------------------
electron/main.mjs
  importe : node:path, node:url, node:fs/promises, electron, ./serialBridge.mjs

electron/serialBridge.mjs
  importe : serialport (module natif npm), electron (BrowserWindow)

electron/preload.cjs
  importe : electron (contextBridge, ipcRenderer)
  (chargé par Chromium pour chaque fenêtre, avant le contenu de la page)


4. Configuration build / serveur Vite
--------------------------------------
vite.config.ts
  lit : package.json (version pour VITE_APP_VERSION)

tsconfig.json
tsconfig.node.json

index.html
  (servi à la racine URL / en dev)


5. Ordre de chargement côté renderer (première navigation)
------------------------------------------------------------
GET / → index.html

Puis le navigateur charge notamment :
- Feuilles de style Google Fonts (réseau, URLs dans index.html)
- /assets/loader_animated.png
- /src/main.tsx (module, transformé à la volée par Vite)


6. Point d’entrée application React
-----------------------------------
src/main.tsx
  importe : react, react-dom/client, ./index.css, ./App

src/index.css

src/App.tsx
  (importe tout le graphe de l’UI : contextes, pages, composants, libs, etc.)
